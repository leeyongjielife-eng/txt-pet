# 松喵喵动画规划

## 设计原则

松喵喵不是高频动作角色。

动画设计以：

- 安静

- 陪伴

- 观察

- 微动作

为核心。

动画应避免：

- 频繁跳跃

- 长时间奔跑

- 夸张动作

- 持续吸引注意力

目标：

让MOA感觉松喵喵一直活着，而不是一直表演。

# V1 核心动画

## 01 待机

优先级：

最高

用途：

默认状态

帧数：

24帧循环

- 轻微呼吸

出现频率：

最高
