# MEMORY_[SYSTEM.md](http://SYSTEM.md)

# 松喵喵记忆系统

## 设计原则

松喵喵拥有轻量记忆。

记忆的目的是增强陪伴感。

不是为了数值养成。

不是为了升级系统。

---

# 存储方式

使用本地 JSON 文件保存。

推荐位置：

data/songnyang_memory.json

---

# 记录内容

## 首次见面

first_met_date

记录第一次启动桌宠的日期。

---

## 累计陪伴天数

days_together

统计与MOA一起度过的天数。

---

## 总互动次数

interaction_count

包括：

- 喂食

- 健身

---

## 可颂次数

croissant_count

统计喂食巧克力可颂次数。

---

## TXT歌曲次数

txt_song_count

统计播放TXT歌曲次数。

---

亲密度计算及其触发依赖已移除。旧存档中的亲密度和已停用功能计数会在迁移时删除。

---

# 不记录内容

不记录：

- 文件内容

- 浏览器内容

- 聊天内容

- 麦克风内容

- 摄像头内容

松喵喵只记录与自己有关的互动。
